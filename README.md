# GitLab contributions mirror

My open-source work happens on GitLab (`gitlab-org/gitlab`, Gitaly, GitLab Shell,
`glab`, the Helm charts, the AI gateway and others). GitHub's contribution graph
only counts commits hosted on GitHub, so this repository holds one small,
dated shadow commit for every commit I authored inside a GitLab merge request.

Nothing here is real code. Each commit message names the project, links the
merge request, and records the original GitLab commit SHA so the history can be
checked. [`CONTRIBUTIONS.md`](CONTRIBUTIONS.md) is the readable log.

- GitLab profile: https://gitlab.com/sjestonsingh
- Generated by [`mirror.py`](mirror.py), which is idempotent and safe to re-run.
